# C#: программа на языке Gearbit

На вкладке **«C#»** программу для робота пишут на языке C#. На нём написан сам Gearbit, а ещё игры на Unity и многие программы для Windows. Это шаг после «Блоков» и Python, примерно с 11–12 лет. Команды те же, что в Python, только с большой буквы и с точкой с запятой в конце: `robot.Forward(50);`.

## Что нужно

Ничего ставить не надо: всё для C# уже есть в Gearbit. Справа от «Запустить» видно, какая версия языка, например «C# 14».

Программа здесь — **скрипт**: команды пишут сразу, без `class` и `Main`. Готовы `robot` и `Wait`, подключены `System`, `System.Linq`, `System.Collections.Generic` и другие частые пространства имён.

## Экран

| Где | Что |
|---|---|
| Сверху | **Запустить**, **Стоп**, состояние программы, **Примеры**, **Новая**, **Открыть**, **Сохранить**. |
| В центре | Текст программы. Над ним — имя файла и пометка «изменена», если программа ещё не сохранена в файл. |
| Внизу | **Вывод**: сюда пишет `Console.WriteLine()`, здесь же ошибки и сообщение «Программа закончилась». |
| Справа | Робот (комната эмулятора или радар) с облачком `robot.Say`, карточка **«Команды»** и **«Датчики»**. |

Щелчок по команде в карточке «Команды» вставляет её в программу под курсором. Если это цикл или `if`, курсор встаёт внутрь фигурных скобок. Пока набираете `robot.`, Gearbit подсказывает команды. **Enter** или **Tab** вставляет команду, а **Tab** потом переходит к следующему числу в скобках. **Ctrl+Пробел** показывает подсказки в любом месте.

## Первая программа

1. Подключите робота или эмулятор (плашка «Нет робота» вверху).
2. Откройте **«Примеры»** → **«Первая поездка»**.
3. Нажмите **«Запустить»** или **F5**.

```csharp
robot.Say("Поехали!");
robot.Forward(50);        // вперёд с мощностью 50
Wait(1);                  // ехать 1 секунду
robot.TurnRight(40);
Wait(0.5);
robot.Backward(50, 1);    // назад 1 секунду и остановиться
robot.Say("Приехали!");
```

Три правила C#, о которых чаще всего забывают:

- в конце каждой команды — точка с запятой `;`;
- большие и маленькие буквы различаются: `Forward`, а не `forward`;
- то, что внутри цикла или `if`, пишут в фигурных скобках `{ }`.

## Команды

### Движение

Мощность — от 0 до 100. Если указать секунды, робот проедет столько и остановится. Без секунд — едет, пока не скажут другое.

| Команда | Что делает |
|---|---|
| `robot.Forward(50);` | Вперёд. `robot.Forward(50, 2);` — 2 секунды и стоп. |
| `robot.Backward(50);` | Назад. |
| `robot.TurnLeft(40);` | Поворот налево на месте. |
| `robot.TurnRight(40);` | Поворот направо на месте. |
| `robot.Drive(50, 30);` | Газ и руль, как стик геймпада. Руль больше 0 — направо, меньше 0 — налево. |
| `robot.Tank(50, 20);` | Левое и правое колесо по отдельности. Отрицательная мощность — назад. |
| `robot.Motor("M3", 50);` | Один мотор. |
| `robot.Stop();` | Остановиться. |
| `Wait(1);` | Подождать 1 секунду. Робот продолжает делать то, что ему сказали. |

### Датчики

| Команда | Что возвращает |
|---|---|
| `robot.Distance("front")` | Расстояние (`int`): 0 — вплотную, 6 — далеко или ничего нет. |
| `robot.Obstacle("front")` | `true`, если препятствие близко (расстояние меньше 2). |
| `robot.DistanceCm("front")` | Сантиметры (`double?`), если датчик откалиброван ([замеры](measurements.md)), иначе `null`. |
| `robot.Tilt()` | Наклон робота: `var (x, y) = robot.Tilt();`. |
| `robot.Battery()` | Заряд батареи. |
| `robot.Connected` | `true`, если робот подключён. |

Датчик называют по месту: `"front"` (впереди), `"right"`, `"left"`, `"back"` и наклонные `"front_right"`, `"front_left"`, `"back_right"`, `"back_left"`. Можно по-русски: `"впереди"`, `"справа"`, `"слева"`, `"сзади"`. Можно по номеру: `"D1"`, `"D2"`. Место датчика — как в карточке «Датчики» на вкладке «Пульт»: переставили датчик там — программа это знает.

### Свет и надписи

| Команда | Что делает |
|---|---|
| `robot.Light("all", "green");` | Все огоньки зелёные. Один огонёк: `robot.Light("L1", "red");`. |
| `robot.LightsOff();` | Выключить огоньки. |
| `robot.Say("Привет!");` | Облачко над роботом на экране. `robot.Say("");` его убирает. |
| `Console.WriteLine("Привет!");` | Напечатать строчку в «Вывод». |

Цвета: `red`, `orange`, `yellow`, `green`, `cyan`, `blue`, `purple`, `white`, `off`. Можно по-русски: `"красный"`, `"зелёный"` и так далее.

## Как останавливать

- **«Стоп»** на панели, **Shift+F5**, большая кнопка **СТОП** в шапке или **Esc** останавливают программу и робота. **Пробел** — тоже, но только когда курсор не в тексте программы: там он ставит пробел.
- Программа останавливается и сама:
  - вы перешли на другую вкладку или свернули окно;
  - связь с роботом пропала;
  - в программе ошибка.
- **Программа закончилась** — робот останавливается. Если он ещё ехал, Gearbit подскажет: чтобы ехать дольше, добавьте `Wait(секунды)` или цикл `while (true)`.

Перед запуском Gearbit собирает программу целиком, поэтому первый запуск занимает секунду-две.

## Ошибки

C# проверяет программу целиком **до** запуска. Если есть ошибка, робот не тронется с места, а Gearbit подсветит строку красным, поставит на неё курсор и напишет в «Вывод», что не так, по-русски. Например:

- «В конце команды нужна точка с запятой «;»»;
- «У робота нет команды «Forwrd». Может быть, robot.Forward?»;
- «Пишите Wait с большой буквы: Wait(1);».

Ниже, в скобках, — то же сообщение самого C# с кодом ошибки (например, `CS1002`). По этому коду удобно искать ответ в интернете.

Ошибки во время работы (деление на ноль, неправильный цвет) тоже показывают строку. Наведите мышь на подчёркнутое место — появится то же сообщение. Кнопка **«Показать строку»** в «Выводе» возвращает к ошибке.

`Console.ReadLine()` здесь не работает: программе нечего ввести с клавиатуры. Числа задавайте прямо в программе.

| Клавиши | Что делают |
|---|---|
| **F5** или **Ctrl+Enter** | Запустить |
| **Shift+F5** или **Esc** | Остановить |
| **Ctrl+Пробел** | Подсказки команд |
| **Tab** / **Shift+Tab** | Отступ вправо / влево |
| **Ctrl+Z** / **Ctrl+Y** | Отменить / вернуть |
| **Ctrl+F** | Найти в программе |

## Примеры

| Пример | Чему учит |
|---|---|
| Первая поездка | Последовательность команд |
| Квадрат | Цикл `for` и строки с `$"…{переменная}"` |
| Исследователь | `while (true)`, `if … else if … else`, два датчика |
| Осторожный водитель | Переменные `var` и расчёт скорости по датчику |
| Светофор | Массив пар и `foreach` |
| Считалка | Переменные и `Console.WriteLine` без робота |

## Сохранение

- Программа **запоминается сама**: закройте Gearbit, откройте снова — текст на месте.
- **«Сохранить»** записывает обычный файл `*.cs`. Его можно открыть в любом редакторе.
- **«Открыть»** загружает файл `*.cs` или `*.csx`. **«Новая»** начинает с чистого листа.

## C# вне Gearbit (для взрослых)

Ту же программу можно запускать из Visual Studio, VS Code или консоли, пока Gearbit открыт и робот подключён. Нужна библиотека `Gearbit.Client`: проект `src/Gearbit.Client` в исходниках Gearbit (пакет NuGet пока не опубликован).

```bash
dotnet new console -n MyRobot
cd MyRobot
dotnet add reference ..\Gearbit\src\Gearbit.Client\Gearbit.Client.csproj
```

В `Program.cs` добавьте одну строку сверху, остальное — как в Gearbit:

```csharp
using static Gearbit.Client.RobotScript;

robot.Forward(50);
Wait(1);
Console.WriteLine($"Впереди: {robot.Distance("front")}");
```

`robot` подключается к Gearbit на `ws://localhost:5280/ws` при первой команде. Другой адрес — переменная окружения `GEARBIT_URL` или свой объект: `using var bot = new Robot("ws://localhost:5290/ws");`. Когда программа заканчивается, робот останавливается и управление освобождается.
