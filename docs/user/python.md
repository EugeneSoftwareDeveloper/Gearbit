# Python: программа текстом

На вкладке **«Python»** программу для робота пишут на настоящем языке Python. Это следующий шаг после «Блоков», примерно с 10 лет. Команды те же: ехать, поворачивать, ждать, смотреть на датчики. Только теперь это строчки текста, например `robot.forward(50)`.

## Что нужно

Python 3.9 или новее на компьютере. Gearbit найдёт его сам.

1. Скачайте Python с сайта [python.org](https://www.python.org/downloads/).
2. При установке отметьте галочку **«Add python.exe to PATH»**.
3. Перезапустите Gearbit.

Если Python не найден, над программой появится жёлтая полоска с подсказкой и кнопкой **«Проверить снова»**. Справа от «Запустить» Gearbit показывает, какой Python он нашёл, например «Python 3.13.0».

Для взрослых: Gearbit ищет Python в таком порядке:

1. путь из настройки `Hub:PythonPath`, например `Gearbit.exe --Hub:PythonPath="C:\Python313\python.exe"`;
2. папка `python\runtime` рядом с Gearbit (туда можно положить портативный Python);
3. лаунчер `py` с python.org;
4. `python.exe` в `PATH`.

## Экран

| Где | Что |
|---|---|
| Сверху | **Запустить**, **Стоп**, состояние программы, **Примеры**, **Новая**, **Открыть**, **Сохранить**. |
| В центре | Текст программы. Над ним — имя файла и пометка «изменена», если программа ещё не сохранена в файл. |
| Внизу | **Вывод**: сюда пишет `print()`, здесь же ошибки и сообщение «Программа закончилась». |
| Справа | Робот (комната эмулятора или радар) с облачком `robot.say`, карточка **«Команды»** и **«Датчики»**. |

Щелчок по команде в карточке «Команды» вставляет её в программу под курсором. Пока набираете `robot.`, Gearbit подсказывает команды. **Enter** или **Tab** вставляет команду, а **Tab** потом переходит к следующему числу в скобках.

## Первая программа

1. Подключите робота или эмулятор (плашка «Нет робота» вверху).
2. Откройте **«Примеры»** → **«Первая поездка»**.
3. Нажмите **«Запустить»** или **F5**.

```python
from gearbit import robot, wait

robot.say("Поехали!")
robot.forward(50)        # вперёд с мощностью 50
wait(1)                  # ехать 1 секунду
robot.turn_right(40)
wait(0.5)
robot.backward(50, 1)    # назад 1 секунду и остановиться
robot.say("Приехали!")
```

Первая строка `from gearbit import robot, wait` нужна в каждой программе для робота: она даёт команды `robot` и `wait`.

## Команды

### Движение

Мощность — от 0 до 100. Если указать секунды, робот проедет столько и остановится. Без секунд — едет, пока не скажут другое.

| Команда | Что делает |
|---|---|
| `robot.forward(50)` | Вперёд. `robot.forward(50, 2)` — 2 секунды и стоп. |
| `robot.backward(50)` | Назад. |
| `robot.turn_left(40)` | Поворот налево на месте. |
| `robot.turn_right(40)` | Поворот направо на месте. |
| `robot.drive(50, 30)` | Газ и руль, как стик геймпада. Руль больше 0 — направо, меньше 0 — налево. |
| `robot.tank(50, 20)` | Левое и правое колесо по отдельности. Отрицательная мощность — назад. |
| `robot.motor("M3", 50)` | Один мотор. |
| `robot.stop()` | Остановиться. |
| `wait(1)` | Подождать 1 секунду. Робот продолжает делать то, что ему сказали. |

### Датчики

| Команда | Что возвращает |
|---|---|
| `robot.distance("front")` | Расстояние: 0 — вплотную, 6 — далеко или ничего нет. |
| `robot.obstacle("front")` | `True`, если препятствие близко (расстояние меньше 2). |
| `robot.distance_cm("front")` | Сантиметры, если датчик откалиброван ([замеры](measurements.md)), иначе `None`. |
| `robot.tilt()` | Наклон робота: два числа `(x, y)`. |
| `robot.battery()` | Заряд батареи. |

Датчик называют по месту: `"front"` (впереди), `"right"`, `"left"`, `"back"` и наклонные `"front_right"`, `"front_left"`, `"back_right"`, `"back_left"`. Можно по-русски: `"впереди"`, `"справа"`, `"слева"`, `"сзади"`. Можно по номеру: `"D1"`, `"D2"`. Место датчика — как в карточке «Датчики» на вкладке «Пульт»: переставили датчик там — программа это знает.

### Свет и надписи

| Команда | Что делает |
|---|---|
| `robot.light("all", "green")` | Все огоньки зелёные. Один огонёк: `robot.light("L1", "red")`. |
| `robot.lights_off()` | Выключить огоньки. |
| `robot.say("Привет!")` | Облачко над роботом на экране. `robot.say("")` его убирает. |
| `print("Привет!")` | Напечатать строчку в «Вывод». |

Цвета: `red`, `orange`, `yellow`, `green`, `cyan`, `blue`, `purple`, `white`, `off`. Можно по-русски: `"красный"`, `"зелёный"` и так далее.

## Как останавливать

- **«Стоп»** на панели, **Shift+F5**, большая кнопка **СТОП** в шапке или **Esc** останавливают программу и робота. **Пробел** — тоже, но только когда курсор не в тексте программы: там он ставит пробел.
- Программа останавливается и сама:
  - вы перешли на другую вкладку или свернули окно;
  - связь с роботом пропала;
  - в программе ошибка.
- **Программа закончилась** — робот останавливается. Если он ещё ехал, Gearbit подскажет: чтобы ехать дольше, добавьте `wait(секунды)` или цикл `while True:`.

## Ошибки

Если в программе ошибка, Gearbit подсвечивает строку красным, ставит на неё курсор и пишет в «Вывод», что не так, по-русски. Например:

- «В строке 5 нет двоеточия»;
- «У робота нет команды «forwrd». Может быть, robot.forward?»;
- «Python не знает «robot». Добавьте первой строкой: from gearbit import robot, wait».

Наведите мышь на подчёркнутое место — появится то же сообщение. Кнопка **«Показать строку»** в «Выводе» возвращает к ошибке.

`input()` здесь не работает: программе нечего ввести с клавиатуры. Числа задавайте прямо в программе.

## Клавиши

| Клавиши | Что делают |
|---|---|
| **F5** или **Ctrl+Enter** | Запустить |
| **Shift+F5** или **Esc** | Остановить |
| **Tab** / **Shift+Tab** | Отступ вправо / влево (в Python отступы важны: они показывают, что внутри цикла или `if`) |
| **Ctrl+Z** / **Ctrl+Y** | Отменить / вернуть |
| **Ctrl+F** | Найти в программе |
| **Ctrl+/** | Закомментировать строку |

## Примеры

| Пример | Чему учит |
|---|---|
| Первая поездка | Последовательность команд |
| Квадрат | Цикл `for` |
| Исследователь | `while True`, `if … elif … else`, два датчика |
| Осторожный водитель | Переменные и расчёт скорости по датчику |
| Светофор | Списки и вложенные циклы |
| Считалка | Переменные и `print` без робота |

## Сохранение

- Программа **запоминается сама**: закройте Gearbit, откройте снова — текст на месте.
- **«Сохранить»** записывает обычный файл `*.py`. Его можно открыть в любом редакторе.
- **«Открыть»** загружает файл `*.py`. **«Новая»** начинает с чистого листа.

## Python вне Gearbit (для взрослых)

Ту же программу можно запускать из VS Code, IDLE или консоли, пока Gearbit открыт и робот подключён. Пакет `gearbit` лежит в папке `python` рядом с Gearbit.exe (в исходниках — в папке `python` репозитория):

```bash
pip install -e python
python моя_программа.py
```

Без установки достаточно добавить эту папку в переменную `PYTHONPATH`. Описание пакета — [python/README.md](../../python/README.md).
