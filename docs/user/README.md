# Gearbit: руководство пользователя

**Русский** · [English](../en/user/README.md)

Gearbit — программа для Windows, с которой робота из конструктора можно водить с компьютера и учить ездить самостоятельно по программе. Удобнее, чем с телефона: большой экран, клавиатура, мышь, геймпад.

Первый поддерживаемый робот — **Apitor / Makerzoid SuperBot** (на коробке может быть написано «Robot Master 200 в 1»). Модели собираются из одного набора: машинка, танк, пёс и другие. Программа работает с любой сборкой, в которой есть моторы и датчики расстояния.

## Что умеет сейчас

- **Пульт**: езда кнопками, клавиатурой, экранным джойстиком или геймпадом Xbox / PlayStation.
- **Датчики**: видно, насколько близко препятствие, наклон робота, заряд батареи. Программа узнаёт, что робота наклонили: «наклонён?», «когда наклонён». Датчик можно переставить на любое место, направить в пол или убрать, если его нет в модели.
- **Езда по линии**: датчики смотрят в пол, и робот сам едет по чёрной изоленте. В Блоках, Python и C# — готовые примеры.
- **Свет и моторы**: цвет каждого светодиода и ручное управление каждым мотором.
- **Блоки**: программа из цветных блоков, как в Scratch. Робот выполняет её сам: едет, светится, объезжает стены. Десять готовых примеров, сохранение в файл.
- **Python**: та же программа, но текстом на настоящем языке. Подсветка, подсказки команд, понятные ошибки, примеры. Нужен Python с python.org.
- **C#**: программа на языке, на котором написан сам Gearbit. Те же команды, подсказки и понятные ошибки, ставить ничего не нужно. Для взрослых — библиотека `Gearbit.Client` для своих программ в Visual Studio.
- **История программы**: Gearbit сам хранит прежние версии программы. «Новая» или пример поверх своей программы ничего не стирают без следа.
- **Замеры** (для взрослых): кадры роботу вручную, тест мощности, калибровка датчиков и запись всего обмена в файл.
- **Эмулятор**: виртуальная машинка в комнате на экране. Можно тренироваться без робота, расставлять препятствия мышкой, включить трассу «Линия» или наклонить машинку.
- **Язык и оформление**: интерфейс на русском или английском (при первом запуске — как в Windows), дневная и ночная тема, пять цветов, крупный текст. Gearbit запоминает выбор, последнюю вкладку и сборку робота.
