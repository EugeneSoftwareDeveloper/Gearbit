# Языки: русский и английский

**Русский** · [English](../en/dev/i18n.md)

Всё, что видит пользователь, есть на двух языках: интерфейс, сообщения хаба, ошибки программ на Python и C#, заставка окна. Журнал хаба, описания методов в `hub.methods` и комментарии в коде остаются на русском: они для разработчика.

Тексты для ребёнка короткие и понятные, с подсказкой, что сделать. Английский текст пишут так же просто, а не переводят слово в слово.

## Как выбирается язык

1. Пользователь выбрал язык в настройках (⚙ → «Язык · Language») — берётся он. Он хранится в `settings.json` хаба (`lang`), см. [API хаба](hub-api.md#http).
2. Иначе — по языку системы: `ru`, `uk`, `be`, `kk` → русский, всё остальное → английский. В интерфейсе это `detectLang(navigator.languages)`, в окне WPF — `CultureInfo.CurrentUICulture`.

Язык выбирается один раз при загрузке страницы. Смена языка сохраняет настройки и перезагружает страницу (`setLang` в `i18n.ts`): черновики программ к этому времени уже в `localStorage`.

Интерфейс передаёт язык хабу в `hub.hello {lang}`. Хаб отвечает этому клиенту на его языке и передаёт язык программе, которую клиент запустил (`GEARBIT_LANG`). Клиент без `lang` получает русские тексты.

## Интерфейс (`web/studio-ui`)

Тексты лежат рядом с кодом, который их показывает:

```ts
import { lang, messages } from "../i18n";

const M = messages({
  ru: { stop: "СТОП", step: (n: number) => `Шаг ${n}` },
  en: { stop: "STOP", step: (n) => `Step ${n}` },
});

button.textContent = M.stop;
```

- `messages()` возвращает словарь языка страницы. Тип `en` выводится из `ru`, поэтому TypeScript не соберёт проект, если в `en` не хватает ключа или у функции другие параметры. Отдельный тест полноты не нужен: `npm run typecheck`.
- `M` вызывается при загрузке модуля, поэтому язык должен быть известен до него. Так и сделано: `main.ts` сначала читает настройки (`syncSettings`), выставляет `document.documentElement.lang` и только потом загружает `app.ts`.
- Даты, время и сортировка — с `lang()`: `toLocaleTimeString(lang(), …)`, `a.localeCompare(b, lang())`.
- Названия языков в переключателе (`LANGS`) всегда на самих этих языках.
- Блоки: свои блоки (`blocks/robot-blocks.ts`), категории (`blocks/toolbox.ts`) и примеры (`blocks/examples.ts`) — на двух языках. Стандартные блоки переводит scratch-blocks: `SB.ScratchMsgs.setLocale(lang())`.
- Python и C#: подсказки, карточка «Команды» и примеры (`code/python.ts`, `code/csharp.ts`) — на двух языках. В английских примерах и комментарии английские.

## Хаб (`src/Gearbit.Hub`)

- Тексты — в `HubText.cs`: интерфейс `IHubText` и классы `RuHubText`, `EnHubText`. Новый текст добавьте в интерфейс и в оба класса — без перевода проект не соберётся.
- У каждого клиента свой `Text` (по `hub.hello {lang}`).
- Ошибка: `throw new HubException(HubErrors.NotFound, t => t.NoMotor(id))`. `Message` исключения — русский текст для журнала, клиент получает текст на своём языке.
- Уведомление с текстом — через `ClientRegistry.BroadcastText`: каждый клиент получает его на своём языке.
- Core и BLE-транспорт текстов для пользователя не пишут: `RobotException` несёт код `RobotErrorCode`, хаб показывает по нему `IHubText.RobotError`.
- Тест — в `HubTests`: тот же вызов с `lang: "en"` и без `lang`.

## Окно (`src/Gearbit.App`)

`AppText.cs`: тексты заставки, окна «Нужен WebView2» и сообщения «Порт занят». Язык — из `settings.json` (`lang`), иначе по `CultureInfo.CurrentUICulture`.

## Python (`python/gearbit`)

- Тексты — в `_texts.py`: словари `RU` и `EN`, `t("key", **params)`. Параметры — в `{фигурных скобках}`.
- Язык: `GEARBIT_LANG`, без него — язык системы (`detect_lang`). Тесты фиксируют русский: `set_lang("ru")`.
- Тест `test_texts.py` проверяет, что ключи и параметры в `RU` и `EN` совпадают.

## C# (`Gearbit.Client`, `Gearbit.ScriptHost`)

- Клиент: `ClientText.cs` — интерфейс `IClientText` и два класса. Язык — `ClientText.Current`: из `GEARBIT_LANG`, без него — по `CultureInfo.CurrentUICulture`.
- Скрипт-хост: `ScriptText.cs` (`IScriptText`) — подсказки к ошибкам Roslyn в `CompileErrors.cs` и `RuntimeErrors.cs`. Исходное сообщение Roslyn показывается в культуре того же языка.
- Новая команда робота — текст ошибки сразу в оба языка и в Python, и в C#.

## Описания роботов (`devices/`, `profiles/`)

Поля, которые видит пользователь (`title` сборки, модели и компонента), пишут объектом по языкам:

```json
"title": { "ru": "Машинка", "en": "Car" }
```

Простая строка тоже работает — она подходит любому языку, поэтому старые и чужие описания не ломаются. В C# это `LocalizedText`, хаб отдаёт поле клиенту как есть, интерфейс выбирает язык функцией `text(title)` из `i18n.ts`.
