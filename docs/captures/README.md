# Записи замеров

Сюда кладутся записи сессий из «Помощника замеров» Gearbit (журнал протокола → «Замеры» → «Запись»). По ним уточняется протокол ([PROTOCOL-SUPERBOT.md](../PROTOCOL-SUPERBOT.md)), обновляются `devices/*.json` и `profiles/*.json`, а реальные кадры становятся «золотыми» данными для тестов.

## Имя файла

`ГГГГ-ММ-ДД-ЧЧММ.capture.json` — так его предлагает Gearbit (время начала записи, UTC). Можно дописать, что за робот или прошивка: `2026-11-06-1530-superbot-v2.capture.json`.

## Формат (`gearbit-capture`, версия 1)

```json
{
  "format": "gearbit-capture",
  "version": 1,
  "startedAt": "2026-11-06T15:30:12.345Z",
  "durationMs": 184000,
  "robot": { "name": "Nordic_TUDAO", "deviceId": "tudao-superbot", "profileId": "superbot-car", "firmware": "v2" },
  "truncated": false,
  "frames": [
    { "at": 1520, "t": 98231, "dir": "out", "hex": "FFFE0901020A000000000000FDFC", "note": "вручную" },
    { "at": 1590, "t": 98301, "dir": "in", "hex": "FFFE0E…FDFC" }
  ],
  "marks": [
    { "at": 1400, "text": "Режим замеров включён" },
    { "at": 9000, "text": "Тест мощности: результаты", "data": { "motor": "M1", "steps": [] } }
  ],
  "events": [
    { "at": 20000, "type": "safety.event", "data": { "reason": "stop", "message": "…" } }
  ]
}
```

| Поле | Смысл |
|---|---|
| `at` | Миллисекунды от начала записи (часы интерфейса). По нему кадры, заметки и события выстраиваются в одну ленту. |
| `t` | Миллисекунды от старта хаба (из `robot.trace`). |
| `dir` | `out` — компьютер → робот, `in` — робот → компьютер. |
| `note` | Пометка хаба: «авторизация», «вручную» и т. п. |
| `marks` | Заметки человека и итоги мастеров «Мощность» и «Датчики» (`data`). |
| `events` | `safety.event` и `robot.state` за время записи. |
| `truncated` | `true`, если кадров было больше 200 000 и хвост не записан. |

**UID робота в запись не попадает**: файлы лежат в открытом репозитории.

## Что делать с записью

1. Положить файл сюда и закоммитить.
2. Перенести выводы в `PROTOCOL-SUPERBOT.md` со ссылкой на файл и в `devices/*.json` / `profiles/*.json`. `verified: true` — только для того, что действительно видно в записи.
