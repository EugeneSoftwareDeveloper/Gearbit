# Gearbit: user guide

[Русский](../../user/README.md) · **English**

Gearbit is a Windows app for driving a construction-kit robot from a computer and teaching it to drive on its own with a program. It is more comfortable than a phone: a big screen, a keyboard, a mouse, a gamepad.

The first supported robot is the **Apitor / Makerzoid SuperBot** (the box may say "Robot Master 200 in 1"). Models are built from one kit: a car, a tank, a dog and others. Gearbit works with any build that has motors and distance sensors.

> The Gearbit interface speaks English and Russian. This guide quotes buttons and blocks as they appear in the English interface: **Connect**.

## What it can do now

- **Remote control**: drive with buttons, the keyboard, an on-screen joystick or an Xbox / PlayStation gamepad.
- **Sensors**: see how close an obstacle is, the robot's tilt and battery level. A program can tell that the robot was tilted: "tilted?", "when tilted". A sensor can be moved to any place, pointed at the floor or removed if your model doesn't have it.
- **Line following**: sensors look at the floor and the robot follows black electrical tape on its own. Ready-made examples in Blocks, Python and C#.
- **Lights and motors**: the color of each LED and manual control of each motor.
- **Blocks**: a program made of colored blocks, like in Scratch. The robot runs it on its own: drives, lights up, avoids walls. Ten ready-made examples, saving to a file.
- **Python**: the same program, but as text in a real language. Highlighting, command hints, clear error messages, examples. Needs Python from python.org.
- **C#**: programs in the language Gearbit itself is written in. The same commands, hints and clear error messages, nothing to install. For grown-ups — the `Gearbit.Client` library for your own programs in Visual Studio.
- **Program history**: Gearbit keeps earlier versions of the program by itself. **New program** or an example over your own program never erases it without a trace.
- **Measurements** (for grown-ups): hand-made frames to the robot, a power test, sensor calibration and a recording of all traffic to a file.
- **Emulator**: a virtual car in a room on the screen. Practice without a robot, draw obstacles with the mouse, switch on the **Line** track or tilt the car.
- **Language and looks**: the interface in English or Russian (on the first launch — as in Windows), day and night theme, five colors, large text. Gearbit remembers your choice, the last tab and the robot build.
