# gearbit для Python

**Русский** · [English](README.en.md)

Пакет для программ, которые управляют роботом через Gearbit. Зависимостей нет, нужен Python 3.9 или новее.

```python
from gearbit import robot, wait

robot.forward(50)          # ехать вперёд с мощностью 50 %
wait(1)                    # подождать секунду
robot.turn_left(40, 0.5)   # полсекунды поворачиваться налево
robot.stop()
```

## Где запускать

- **В Gearbit**, вкладка «Python»: пишете, нажимаете «Запустить». Пакет ставить не нужно.
- **В VS Code, IDLE или консоли**: Gearbit должен быть запущен, робот (или эмулятор) подключён.

```bash
pip install -e python/
python моя_программа.py
```

Программа подключается к `ws://localhost:5280/ws`. Другой адрес задаётся переменной окружения `GEARBIT_URL`.

Сообщения и ошибки пакет пишет на языке системы: по-русски для русской, украинской, белорусской и казахской Windows, иначе по-английски. В Gearbit — на языке вкладки. Задать язык явно: переменная окружения `GEARBIT_LANG=ru` или `en`.

## Безопасность

- Предел мощности для детей применяет Gearbit, а не программа.
- СТОП в Gearbit, потеря связи и страж останавливают робота, а программа заканчивается с сообщением «Программа остановлена».
- Когда программа заканчивается, она сама выключает свои моторы.
